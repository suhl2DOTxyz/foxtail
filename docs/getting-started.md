# Getting started

## The keys
Foxtail uses the Mac layout of shortcuts on a PC keyboard:

| Mac | PC key |
|---|---|
| ⌘ Command | the **Windows / Super** key |
| ⌥ Option | **Alt** |
| ⌃ Control | **Ctrl** |

So copy is ⌘C (**Super+C**), Spotlight is ⌘Space, switching apps is ⌘Tab. They work in every app, terminals included.

## Where things are
| | |
|---|---|
| **Fox menu** (top left) | About, System Settings, Software Update, App Store, Sleep, Restart, Shut Down, Lock |
| **Menu bar** | The front app's menus; Wi-Fi, Control Center, Spotlight and the clock on the right |
| **Control Center** | Wi-Fi, Bluetooth, Liquid Glass, dark mode, Focus, display and sound |
| **Clock** | Notification Center, with the calendar and widgets |
| **Dock** | Your apps; Downloads and the Trash on the right |
| **Apps** (F4) | Every app |
| **Mission Control** (F3) | All windows and desktops |

## Coming from Windows
- Close a window with the **red** dot (top left) or ⌘W; quit an app with ⌘Q.
- The Dock is your taskbar; Spotlight (⌘Space) is your Start menu search.
- Files is your File Explorer. Screenshots go to the Desktop.

## Handy shortcuts
| | |
|---|---|
| ⌘Space | Spotlight |
| ⌘Tab | Switch apps |
| ⌘Q / ⌘W | Quit app / close window |
| ⌘H / ⌘M | Hide / minimize |
| ⌃⌥ ← → | Tile a window to a half |
| ⇧⌘3 / ⇧⌘4 / ⇧⌘5 | Screenshot screen / area / options |
| ⌥⌘V | Clipboard history |
| ⌃⌘Space | Emoji & Symbols |
| ⌃⌘Q | Lock |
| ⌥⌘Esc | Force Quit |

The full list is in **System Settings ▸ Keyboard**.
